Ruling: the script still doesn't look for an earlier good capture itself; the playbook says how to find one by hand — cost if wrong: a few minutes per flagged source each month.
- Ruling (Andrew asked for units such as Xijing Hospital to match their parent): a subunit is matched only when the researcher marks it `"match": true`, never automatically — generic unit names (口腔医院 "Stomatological Hospital", 理学院 "School of Science") and campus names are shared by many institutions and would flag unrelated co-authors. A marked unit is judged like an alias (the parent's city confirms; otherwise "check"; placed abroad, no match), reports `matchedBy: 'unit'` with the unit's name, and loses to a direct name match on the same line. 医院 joined the Chinese full-name endings, so a hospital's full Chinese name confirms like a university's — "a marked unit matches its parent…", "a marked unit's Chinese name confirms…", "the search box finds an institution by a marked unit" RED→GREEN; "an unmarked unit never matches on its own" and "a line that also names the parent…" pin the limits — cost if wrong: a researcher who forgets the mark leaves a hospital-only line unmatched.
