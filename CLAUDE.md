# Research Security Toolkit: project reference

This is the launch-safety candidate, based on the audit of 9fa4db4 and integrated with master 3a44e38. The canonical scope is docs/two-person-launch-plan.md; actual completion evidence is docs/launch-closure-record.md.

- Static React 19 / Vite, hash routes, self-hosted fonts, no backend or accounts.
- Node 24.21.0 is pinned in .node-version and .nvmrc. Install with npm ci.
- Run npm run verify and npm run test:e2e before release. npm run check:data rejects overdue source reviews; a date-only edit is not source verification.
- Twelve reviewed tools plus About are exposed. dual-use, travel-security and report-concern from newer master are retained as source but disabled and absent from the build. Their old content is not part of the release evidence.
- The old STRA classifier and geographic risk inference remain removed. The owner explicitly approved restoring diagrams and the NRO map in RC2. Use the corrected shared flow data, attributed approximate location records, safe DOM popup text and separate opt-ins for Wikipedia place searches and OpenStreetMap street tiles. Leaflet and dagre are pinned. Do not reintroduce legacy coordinates, automatic geocoder fallbacks or proximity-as-affiliation claims through a merge. See docs/visual-tools-restoration.md.
- src/data/policySources.js is the source registry. Keep consequential claims consistent with docs/policy-rule-matrix.md and update source/claim records with actual review evidence.
- NSGRP: applicable program plus qualifying private-sector partner requires the RAF even when no risk is identified. STRAC is a separate submission/compliance analysis.
- STRAC: consider affiliation, funding and in-kind support; agency-specific named roles; application-date list versions and whole-team duties. No automatic eligibility or nationality-based inference.
- Ontario: two years before signing through anticipated completion, broader collaboration definitions, separate NRO and other-concern disclosures.
- src/lib/assessment.js validates schema/content version and known answers. State is temporary by default. Explicit opt-in saves only the worksheet. New, resume, undo and clear have distinct semantics.
- src/components/ui/ReferenceGuide.jsx uses a complete print-only DOM. Never make printed completeness depend on open accordions or current filters.
- Source currency rechecks on interaction, visibility changes and each minute. Overdue policy paths disable definitive outputs. Device time is a bounded signal, not trusted policy truth.
- src/styles/global.css preserves this checkout's forest/copper visual system. safety.css supplies accessibility, native controls, reflow and complete print layouts.
- src/data/releaseStatus.js controls operator, reporting contact, disabled tools and containment. User-confirmed operator: Andrew Austin at Lakehead University; contact security.research@lakeheadu.ca. No formal institutional endorsement is asserted.
- VITE_CONTAINMENT=1 produces a source-links fallback and selects the containment browser suite. Test it before relying on it.
- CI creates verified artifacts without publication privileges. Production host choice is deferred by the owner. public/_headers and public/.htaccess are host-specific candidates; GitHub Pages ignores them.
- Keep public license notices generated by scripts/write-notices.js. LICENSE from master identifies the original software copyright holder as Seaway Digital. Operator attribution does not silently rewrite that copyright.
- Existing .claude/launch.json and other preexisting local files are user work. Do not stage their local edits with this release.
- Do not mark independent legal, institutional, security or accessibility certification complete. Only the user and Codex prepared this update.
